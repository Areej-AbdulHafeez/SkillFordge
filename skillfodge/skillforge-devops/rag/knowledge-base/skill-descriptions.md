# Skill Descriptions Knowledge Base

- **Python**: general-purpose programming language; used for scripting, backend services, and AI/ML.
- **Web Development**: building responsive, interactive user interfaces and client-server applications.
- **Git**: version control system for tracking code changes and collaborating with teams.
- **DevOps**: practices and tools for automating build, test, and deployment (Docker, CI/CD, Kubernetes).
- **AI**: techniques for building intelligent features, including generative AI, RAG, and agentic workflows.
- **Database**: designing, querying, and managing structured (SQL) and unstructured (NoSQL) data stores.
