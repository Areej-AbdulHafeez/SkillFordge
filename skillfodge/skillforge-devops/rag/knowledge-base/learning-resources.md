# Learning Resources Knowledge Base

## Python
- Official docs: python.org/doc
- Recommended project: build a CLI tool using OOP (classes for a task manager)
- Core topics: data structures, OOP, error handling, virtual environments

## Web Development
- Recommended path: HTML/CSS -> JavaScript -> React
- Recommended project: a responsive portfolio site, then a full CRUD app
- Core topics: responsive design, component architecture, state management

## Git & GitHub
- Recommended path: basic commands -> branching -> pull requests -> collaboration
- Recommended project: contribute to an open-source repo
- Core topics: commits, branches, merge conflicts, .gitignore, README writing

## DevOps
- Recommended path: Linux basics -> Docker -> CI/CD -> Kubernetes
- Recommended project: containerize a personal project and deploy it
- Core topics: containers, orchestration, infrastructure as code

## AI / Machine Learning
- Recommended path: Python -> statistics -> ML fundamentals -> LLM APIs
- Recommended project: a RAG-based Q&A tool over your own notes
- Core topics: embeddings, prompting, retrieval, evaluation

## Databases
- Recommended path: SQL fundamentals -> schema design -> MongoDB/NoSQL
- Recommended project: design and query a schema for a real app
- Core topics: normalization, indexing, aggregation pipelines
