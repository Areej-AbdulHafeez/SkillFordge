# Career Roadmaps Knowledge Base

## AI Engineer
1. Strong Python fundamentals
2. Web development basics (to ship AI features in real apps)
3. ML/LLM fundamentals: embeddings, prompting, RAG, fine-tuning basics
4. Agentic AI: tool use, function calling, orchestration
5. Deployment: Docker, basic MLOps

## Full-Stack Developer
1. HTML/CSS/JavaScript fundamentals
2. A frontend framework (React)
3. Backend: Node.js/Express, REST APIs
4. Databases: SQL and NoSQL
5. Auth, deployment, and basic DevOps

## DevOps Engineer
1. Linux fundamentals and shell scripting
2. Git and CI/CD pipelines
3. Docker and containerization
4. Kubernetes orchestration
5. Infrastructure as Code (Terraform)

## Data Engineer
1. Python and SQL fundamentals
2. Data modeling and ETL pipelines
3. Databases: relational and NoSQL
4. Distributed data processing basics
5. Cloud data platforms

## Backend Engineer
1. A backend language (Python/Node.js)
2. API design (REST, authentication)
3. Databases and caching
4. Testing and CI/CD
5. Containerization and deployment
